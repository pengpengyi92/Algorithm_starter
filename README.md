# 🚀 Algorithm Starter：推荐 × 搜索 × LLM

欢迎来到《算法起点计划》！这是一个为初学者准备的 AI 三大核心方向入门项目：

📌 推荐系统 —— 帮你发现你不知道你想要的  
📌 搜索算法 —— 帮你找到你说你想要的  
📌 大语言模型（LLM）—— 帮你生成你未来可能想要的

> 本项目内容轻盈简洁，重点介绍核心逻辑与直观思路，适合初学者快速建立系统认知。

🎁 深度内容将在未来“进阶项目”中开放，如你感兴趣，欢迎关注我们/加入讨论社群！
